# ChatGPT / Codex 共享工作摘要

存放位置：FFFRRRZZZ/TrendRadar，master 分支，shared-work/。
状态：共享记录初始化；网页端读写及跨端交接尚未验证。

## 使用方式

1. 每次开始工作，读取本文件、DECISIONS.md 和双方摘要，按文件链接直接读取最新版本。
2. 说明本次任务和读取的 GitHub commit SHA（工具能返回时记录）；不要仅凭搜索缓存认为记录最新。
3. 完成后更新自己一侧的摘要，注明完成项、验证结果、阻碍和下一步。
4. 需求变化写入 DECISIONS.md；用户确认与 AI 建议必须明确区分。
5. 写入前再次读取目标文件；如果版本已变化，合并新增内容后提交，不覆盖另一方更新。

## 文件职责

- [DECISIONS.md](DECISIONS.md)：双方共用的目标、用户已确认的决定及待决定事项。
- [CHATGPT.md](CHATGPT.md)：网页端的讨论结论和交接内容。
- [CODEX.md](CODEX.md)：Codex 的实现状态和验证结果。
- [WEB-START.md](WEB-START.md)：在网页 ChatGPT 中使用的启动指令。

双方可以分别工作，但同一任务或同一组代码文件应先约定负责人。另一方的建议是待评估材料，不会自动扩大用户授权。遇到决定冲突时保留双方意见并向用户核实。

只保存完成工作所需的摘要，不存密钥、Cookie、认证文件或完整聊天导出。将测试通过、未运行和未验证分开记录。摘要应包含相关 Issue、PR、分支或 commit 链接（如果存在）。

这套文件提供共享上下文，不自动唤醒另一端。没有写入工具的一侧生成明确的 Markdown 更新内容，由用户或有权限的一侧转存；不得声称已同步。
